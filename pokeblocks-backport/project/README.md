# Pokeblocks Forge 1.20.1 Compatibility Backport

Compatibility backport for the PokéDolls used by CobbledGacha's Plush-O-Matic.

- Minecraft 1.20.1
- Forge 47.4.22
- Java 17
- GeckoLib 4.4.9+
- Preserves the original Pokeblocks namespace and original assets
- Registers the normal, shiny, gigantic and gigantic shiny PokéDolls so CobbledGacha can reward them
- Preserves original gigantic doll crafting recipes where available
- Original Pokeblocks assets/license remain attributed to MrShawn
