# Cobblemon Progression Bridge

Bridge de progresión para **Minecraft 1.20.1 + Forge 47.4.22 + Cobblemon 1.5.2**.

Integra mediante scoreboards:
- Mass Outbreaks 1.1.4
- Enhanced Celestials / Blood Moon
- Serene Seasons
- VeryScuffedCobblemonBreeding 1.0.9
- Biomes O' Plenty y Regions Unexplored
- Legendarios y míticos

Las integraciones opcionales se implementan con reflexión o mixins @Pseudo para no volverlas dependencias obligatorias.

GitHub Actions compila el JAR automáticamente en cada push a main.
